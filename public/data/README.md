# Data files

This directory stores the editable source data for the Thirukkural book.

- `thirukkural_tamil.json` — Tamil base text and explanations
- `thirukkural_EN.json` — English translation content
- `thirukkural_de.json` — German translation content
- `detail.json` — chapter, section, and group metadata
- `user_img_b64.txt` — cover image payload

Each language has its own JSON file so the project can grow with more languages in the future without mixing source data.
